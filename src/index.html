扫描入口

添加项目或项目集合的目录。外层 control-panel.json 用 children 声明深层子项目。

显式声明的 children 会继续向下发现，不受入口扫描范围影响。

外层项目声明示例

{
  "name": "研究工作区",
  "kind": "collection",
  "children": [
    { "path": "repos/api", "role": "api" },
    { "path": "repos/reader/apps/web", "role": "frontend" }
  ]
}

每个子目录保留自己的 control-panel.json。纯集合只组织服务，不拥有进程；有独立服务的父项目使用 kind: project。
